# Task API

A simple CRUD REST API built using FastAPI.

## Features

- Get all tasks
- Get a task by ID
- Create a task
- Update a task
- Delete a task
- Health check endpoint

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
uvicorn main:app --reload
```
